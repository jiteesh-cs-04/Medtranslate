Document understanding workflow

What happens between “upload” and “explained”

Every document goes through the same careful pipeline, so results are consistent and checked before you see them.

  1. {{ icon('upload', 22) }}

    Upload

    You choose a PDF or image.

  2. {{ icon('file-check', 22) }}

    Validate

    File type, size and integrity are checked.

  3. {{ icon('scan', 22) }}

    Extract

    Text is read from PDFs; images are prepared for scanning.

  4. {{ icon('sparkles', 22) }}

    Understand

    AI organises the content into a fixed structure.

  5. {{ icon('book', 22) }}

    Explain

    You get a summary, details and questions.

Every result follows one structure

Whatever the document, the response is normalised to the same shape, so nothing is silently dropped and a safety disclaimer is always included.

  • {{ icon('check', 16) }} Document type is identified
  • {{ icon('check', 16) }} Medicines and tests are listed separately
  • {{ icon('check', 16) }} Questions for your doctor are suggested
  • {{ icon('check', 16) }} Disclaimer is added to every result
// shape of every analysis result
{
  "document_type": "prescription" | "lab_report",
  "summary": "Plain-language overview…",
  "medicines": [ { name, strength, dosage,
                 frequency, timing, duration,
                 purpose, important_information } ],
  "tests": [ { name, result, unit, reference_range,
             status, what_it_measures, explanation } ],
  "questions_for_doctor": [ "…" ],
  "disclaimer": "Educational only…"
}

Safety and trust

Designed to inform — never to replace your doctor

Medical information deserves care. These principles shape every part of MedTranslate.

{{ icon('book', 22) }}

Educational only

Explanations help you understand a document. They are not medical advice, diagnosis or treatment.

{{ icon('stethoscope', 22) }}

Doctor stays in charge

Each result suggests questions to bring to your clinician before you change anything.

{{ icon('trash', 22) }}

Temporary files

Uploads are stored briefly for processing and removed from the server when analysis finishes.

{{ icon('lock', 22) }}

No accounts or database

This version has no user accounts and keeps no document history. Nothing about you is stored.

{{ icon('file-check', 22) }}

Validated uploads

Only PDF, PNG and JPG files are accepted, and corrupted or oversized files are rejected.

{{ icon('alert', 22) }}

Honest about limits

AI can misread a scan. Always check explanations against your original document.

About MedTranslate

Medical language shouldn’t be a barrier to understanding your own health

Prescriptions are written in abbreviations and lab reports in ranges and units. MedTranslate is an open-source project that translates that shorthand into plain, structured explanations, so patients and families can ask better questions and feel more confident at the appointment.
